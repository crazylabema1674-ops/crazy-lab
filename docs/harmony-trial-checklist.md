# ハモリアプリ 既存サービス試用チェックリスト

作成: 2026-11-22
状態: **未実施**（ユーザーが試すタイミングを見計らい中）

既存のAIハモリサービス（まずは Wondera の無料枠）を試すときの確認項目です。
試した後は、この結果をもとに「自分でアプリを作る価値があるか」「どこで差をつけるか」を判断します。
結果は各項目の □ を ☑ にし、「メモ」欄に感想を書いてください（口頭で伝えてもらえれば、こちらで記入します）。

---

## 0. 準備

- [ ] 試すサービス: Wondera（https://wondera.ai/tools/ja/AI-harmonies-duet ）／比較できれば Kits.ai・Audimee も
- [ ] 録音: スマホの「ボイスメモ」（iPhone）／「レコーダー」（Android）で、**静かな部屋**でアカペラを録音
- [ ] 曲: 普段よく歌う流行りのJ-POP。最初は**サビだけ（30秒〜1分）**、余裕があれば1曲まるごと
- [ ] イヤホン（できれば有線）を用意
- [ ] 利用規約で「アップロードした音声の扱い」をざっと確認

## 1. 使い始めるまで

- [ ] スマホのブラウザで使えたか（使えなければ、パソコン／iPhoneアプリのどれで使ったか）
- [ ] 登録に必要だったもの（メールアドレス、Googleアカウントなど）
- [ ] 画面は分かりやすかったか（英語のみ／日本語あり、迷った所）
- [ ] 無料で何回・何秒まで作れたか

## 2. ハモリの品質

- [ ] **音程**: ハモリの音は合っていたか（外れて気持ち悪い所はあったか、どのあたりか）
- [ ] **歌詞**: ハモリで歌詞がはっきり聞こえたか
- [ ] **声の自然さ**: 上手な歌手に聞こえたか／ロボットっぽかったか
- [ ] **声の種類**: 選べた声の中に好みの声はあったか（男性・女性、高い・低いハモリ）
- [ ] **タイミング**: 自分の歌とハモリのズレはなかったか
- [ ] **長さ**: 1曲まるごと作れたか（上限は何秒だったか）
- [ ] 1曲作るのにかかった待ち時間（およそ何秒・何分）

メモ:

## 3. 一緒に歌ってみた体験（いちばん大事）

- [ ] ハモリを再生しながら、イヤホンでもう一度一緒に歌ってみたか
- [ ] **楽しかったか**（5段階: 1 つまらない 〜 5 とても楽しい）: ＿
- [ ] YouTubeのハモリチャンネルに重ねて歌ったときと比べてどうだったか（良い・同じ・悪い、その理由）
- [ ] 2回目に歌ったとき、ハモリにうまく合わせられたか（テンポのズレは気になったか）
- [ ] 洗い物中・車内・お風呂など、**普段の場面でも使えそうか**（使えない場合、何が邪魔か）
- [ ] また使いたいと思ったか

メモ:

## 4. 面倒だった点・欲しいと思った機能

- [ ] 操作で面倒だった所（録音 → アップロード → 設定 → 再生の流れ）
- [ ] 「こうだったらいいのに」と思った所（例: 声で頼みたい、スマホだけで完結したい、直しを頼みたい）
- [ ] 「サビだけもっと高く」のような**部分的な直し**はできたか、欲しかったか

## 6. 総合判断（試した後に一緒に整理）
