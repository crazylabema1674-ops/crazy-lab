# 調査メモ: 「写真を撮っても見返せない・活用できていない」課題は本当にあるか

調査日: 2026-11-09（Web検索による机上調査。ヒアリング〔フェーズ0〕とは別）

## 結論（要約）

- **課題があること自体は、ほぼ確か。** 日本・海外の複数の調査で「整理できていない」「大半の写真は二度と見られない」という結果が出ている。解決をうたうサービスも多い。
- **ただし「困っている」より「気にはなっている」程度の、弱い悩みである可能性が高い。** 見返さない・整理しない理由の1位は「面倒」「時間がない」。お金を払ってまで解決する人は限られる。
- **一般的な「振り返り」機能は競合が多すぎる。** Apple・Google の写真アプリ自体が無料で「思い出」機能を持ち、みてねも国内のパパママの多くが使っている。
- → **「見返せない」だけを売りにするのは弱い。** 健診・誕生日・入園など **「振り返る必要がある具体的な場面」と結びつけるのが良い**。現在の「健診まとめ」の方針を後押しする結果。

## 1. 課題の裏付けになるデータ

| 調査 | 内容 | 注意点 |
|---|---|---|
| ヨメルバ（子供の写真・制作物の整理、470人） | 整理を後回しにしている 54.7%、整理しているが満足していない 32.8%。満足しているのは 9.6% のみ | 対象は子育て世帯 |
| アスカネット（2025年5月、20〜60代 597人） | 写真整理ができていない人の理由: 「面倒」36.2%、「時間がない」27.1%、「写真が膨大」18.1% | フォトブック会社の調査 |
| MMD研究所（2023年） | スマホ写真の保存先は「本体」88.8%、平均 約1,400枚 | 子供の写真に限らない |
| すくコム（子供の写真のプリント） | 「プリントしたい」94%、実際にプリントしているのは 46% | やりたいのに、やれていない差が大きい |
| Popsa「Memory Economy」（2026年、欧米 8,000人） | スマホ写真の約70%は二度と見返されない。量が多すぎること、見返すと複雑な気持ちになることが理由。カメラロールは「思い出」ではなく「保管庫」になっている | フォトブック会社の調査。日本ではない |
| Mixbook（2023年、米国 約2,000人） | 50%が撮った写真で何もしていない。親の写真は子供の写真が中心 | フォトブック会社の調査 |
| NEC LAVIE（紙の写真） | 紙で保存している人の約40%がほとんど見返さない。理由は「取り出すのが面倒」 | 古い調査 |

**読み方の注意:** 多くは写真プリント・フォトブックを売る会社の調査なので、「課題が大きい」と見せたい傾向がある。数字は目安として扱う。

## 2. 解決をうたうサービス（＝悩みがある証拠であり、競合でもある）

| 種類 | 例 | 本アプリとの関係 |
|---|---|---|
| スマホ標準の写真アプリ | iPhone「写真」のメモリー、Googleフォトの「思い出」 | **無料・自動で振り返りを出してくれる最大の競合**。ただし健診や発達の観点はない |
| 家族アルバム・共有 | 家族アルバム みてね（世界3,000万人超、国内のパパママの約65%が利用〔2026年5月発表〕）、ノハナ、すくすくぱしゃ | 1秒動画などの振り返り機能あり。写真がみてねにしか無い家庭は本アプリで読めない |
| プリント・フォトブック定期便 | Famm、みてねのプリント・フォトブック、ノハナ | 「形に残す」ことでお金を取っている。市場はある |
| 写真整理の代行 | 写真整理の代行業者、アルバム作成の副業 | 「時間がない共働き世帯」がお金を払う例 |
| 海外のAI系サービス | Popsa（写真から自動でフォトブック）、カメラロール整理のスタートアップ | AIで「選ぶ手間」を減らす方向が主流 |

→ サービスが多いことから、**悩みは広くある**と言える。一方で、**一般的な振り返り・整理の市場はすでに混み合っている**。

## 3. この企画への示唆

1. **「見返せない」は入口、「健診で困る」が買う理由。** 「見返せない」は多くの人が共感するが、放っておいても困らない。健診の問診票のように **締め切りと具体的な困りごとがある場面** だと、お金を払う理由になる。
2. **手間ゼロに近いことが必須。** 整理しない理由の1位は「面倒」。タグ付けなどの作業が多いと、このアプリも「撮りっぱなし」と同じ運命になる。マイルストーン起点で候補を絞る現在の設計は合っている。
3. **スマホ標準の「思い出」機能との違いを一言で言えるようにする。** 例: 「標準アプリは思い出を見せてくれる。このアプリは健診で使える記録にしてくれる」。
4. **「好きの記録」（検討中のアイデア）は、標準アプリやみてねと重なりやすい。** 拡散用の楽しい機能としてはよいが、主軸にするなら差別化を再検討する。

## 4. ヒアリング（フェーズ0）で確かめたいこと

- 「見返せていない」ことに対して、**実際に何か行動したか**（フォトブックを作った、プリント定期便を契約した、整理に時間をかけた、代行を頼んだ）。行動・支払いがあれば強い悩み、なければ弱い悩み（既存の H3・H8・H10、D9 と合わせて確認）。
- スマホ標準の「思い出」機能やみてねの振り返り機能を見ているか、それで満足しているか。
