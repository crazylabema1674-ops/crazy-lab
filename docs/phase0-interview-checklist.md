# フェーズ0 ヒアリングチェックリスト（子供の発達記録アプリ）

> 目的：コードを書く前に、子育て中の知人5〜10人へのヒアリングで「この課題は本当にあるか」「このやり方で解けるか」「お金を払うか」を確かめる。
> 1人あたり約30〜35分。対面でもオンラインでもよい。録音する場合は必ず事前に許可をもらう。

---

## 0. このチェックリストの使い方

1. 事前に「2. 対象者の条件」で相手が当てはまるか確認する
2. 当日は「3. 質問項目」を上から順に進める（全部聞けなくてもよい。★印は必須）
3. 聞きながら「5. 記録用テンプレート」に書き込む（その場で書けなければ、終わってすぐに書く）
4. 5人終わった時点で一度集計し、質問を見直す → 残りの人に聞く
5. 全員終わったら「6. ヒアリング後の判断」で Go / 修正 / 中止 を決める

**大事な姿勢**：このヒアリングはアイデアを売り込む場ではなく、**相手の過去の行動と困りごとを教えてもらう場**。アプリの説明は最後の5分まで我慢する。

---

## 1. ヒアリングの目的と検証したい仮説

### 1-1. 目的

- 「健診の問診票で、過去の発達を思い出せずに困る」という課題が**本当に・どのくらいの頻度で・どのくらいの強さで**起きているかを確かめる
- 「スマホの写真から振り返る」という解決方法が**技術的・習慣的に成り立つか**（写真が端末にあるか、兄弟が混ざるか）を確かめる
- **誰が・何に・いくらなら**お金を払うかの手がかりを得る

### 1-2. 仮説と判断基準

| # | 仮説 | 成立と判断する回答 | 不成立と判断する回答 |
|---|------|------------------|------------------|
| H1 | 発達の記録（できた日）を継続的につけられていない親が多い | 「最初は書いてたけど途中でやめた」「母子手帳の欄が空欄」など、**記録が途切れた具体的な話**が出る（目安：半数以上） | 母子手帳・育児アプリで継続して記録できている人が大半。または「記録しなくても困らない」 |
| H2 | 健診の問診票記入で過去を思い出すのに苦労している | 「何ヶ月で歩いたか思い出せず適当に書いた」「写真を遡って探した」「パートナーに聞いた」など**具体的なエピソード**が出る（目安：半数以上） | 「特に困らなかった」「だいたいで書けばいいと思っている」「問診票は数分で書けた」 |
| H3 | 困ったときに実際に写真を見返して思い出している（＝写真が手がかりとして役立つ） | 「カメラロールを遡った」「みてねで探した」など、**すでに写真で代用している行動**がある | 写真を見返したことはない／見返しても日付が分からず役立たなかった |
| H4 | 子供の写真は主にスマホ端末内にあり、アプリから読み取れる | 写真の大半が端末内（iCloud写真で「オリジナルを保持」含む）にある（目安：7割以上の人） | 端末容量の都合で削除済み／Googleフォトのみ／iCloud最適化で端末にほぼ無い／みてねにしか無い人が多い |
| H5 | 写真で分かる項目（歩行・つかまり立ち等）が問診で困った項目と重なる | 困った項目に「歩き始め」「はいはい」「つかまり立ち」など**動きの項目**が含まれる | 困ったのは主に「言葉の数」「指差し」「指示の理解」など**写真では分からない項目**だけ |
| H6 | 兄弟の写真の混在は大きな障害にならない（または手作業で区別できる） | 一人っ子が多い、または「上の子と年齢が離れているので見れば分かる」 | 兄弟が一緒に写る写真が多く、区別に手間がかかると明言 |
| H7 | 既存アプリ（みてね・ぴよログ・母子手帳アプリ等）では、この課題が解決していない | 使っているが「健診の時に結局まとまっていない」「探しにくい」と不満がある | 「みてねの○○機能で十分」「ぴよログで記録している」で満足している |
| H8 | 健診まとめ／PDF出力に500円程度を払う意思がある | 過去に**育児系アプリ・サービスにお金を払った経験**があり、似た価値に払ってもよいという反応（目安：3割以上） | 有料アプリに一度も払ったことがない人が大半／「無料なら使う」止まり |
| H9 | 写真を端末内で処理する仕組みなら、プライバシー面の抵抗は小さい | 「端末内なら気にしない」「みてねにもう上げているので平気」 | 「子供の写真をアプリに見せること自体が嫌」と強い抵抗がある |
| H10 | 写真を見返せておらず、子供の「好き・夢中」を写真から振り返ることに価値がある（追加機能「好きの記録」の検証） | 「量が多すぎて見返さない」など**見返せていない理由**が具体的に出る／子供の好き・得意を知るために**写真を見返したり、習い事選びで迷ったりした経験**がある | 写真は定期的に見返せている／子供の好きなものは普段の様子で十分分かっている／習い事は近さ・友達など写真と関係ない理由だけで決めた |

> 判断の目安の「半数以上」などは、5〜10人という少人数なので**絶対の基準ではない**。「強い困りごとを語った人が何人いたか」を重視する。

## 2. 対象者の条件と属性確認項目

### 2-1. 対象者の条件（スクリーニング）

**必須**
- [ ] 5歳以下の子供がいる
- [ ] 1歳半健診 または 3歳児健診を**すでに受けた**、または**3ヶ月以内に受ける予定**
- [ ] 普段スマホで子供の写真を撮っている

**できれば混ぜたい人（偏りを防ぐ）**
- [ ] iPhoneユーザーとAndroidユーザーの両方
- [ ] 一人っ子の家庭と兄弟がいる家庭の両方
- [ ] ママとパパの両方（問診票を書く人と書かない人で感じ方が違うため）
- [ ] みてね等の共有アプリを使っている人と使っていない人

**避けたい人**
- 自分のアイデアに気を遣って「いいね」と言ってしまいそうな、極端に近しい人だけで固めない（家族は対象外にするのがおすすめ）

### 2-2. 属性確認項目（冒頭2分で確認）

| 項目 | 選択肢・記入例 |
|------|-------------|
| 回答者 | ママ／パパ／その他 |
| 子供の人数 | 1人／2人／3人以上 |
| 各子供の年齢（月齢） | 例：第1子 4歳2ヶ月、第2子 1歳8ヶ月 |
| 受けた健診 | 1歳半健診（受けた／予定／未定）、3歳児健診（受けた／予定／未定） |
| 問診票を主に書いた人 | 自分／パートナー／一緒に |
| スマホOS | iPhone／Android（機種が分かれば） |
| パートナーのOS | iPhone／Android／同じ |
| 働き方 | 共働き／片働き／育休中 など（任意） |
| 住んでいる自治体 | 任意（自治体によって問診票の内容が違うため） |

## 3. 質問項目（約30〜35分）

全体の流れと時間配分：

| パート | 内容 | 目安 |
|-------|------|-----|
| A | あいさつ・趣旨説明・属性確認 | 3分 |
| B | 現状の記録行動 | 5分 |
| C | 健診時の体験（最重要） | 8分 |
| D | 写真の保存場所と撮影習慣・見返し方 | 7分 |
| E | 兄弟の有無と写真の混在 | 2分 |
| F | 既存アプリの利用 | 3分 |
| G | 支払意思 | 2分 |
| H | プライバシー感覚 | 1分 |
| I | アイデアの提示と反応・お礼・お願い | 3分（＋お願い） |

### A. あいさつ・趣旨説明（3分）

- 「子育て中の人が、子供の成長をどう記録しているかを知りたくて話を聞いています」
- 「正解はないので、普段どおりのことを教えてください。うまくできていないことの話が一番ありがたいです」
- **ここではアプリのアイデアは言わない**（言うと相手が気を遣って話を合わせてしまう）
- 録音・メモの許可を取る
- 2-2の属性確認

### B. 現状の記録行動（5分）

- ★B1. 子供が「初めて寝返りした」「初めて歩いた」みたいな日を、どこかに残していますか？ 残しているなら、どこに？（母子手帳／育児アプリ／手帳／SNS／写真だけ／何もしていない）
- ★B2. 最後にそれを書いた（残した）のはいつですか？
- B3. 最初は書いていたけど途中でやめた、ということはありますか？ それはいつ頃、なぜですか？
- B4. 母子手帳の「保護者の記録」（首すわり・寝返り・はいはい・ひとり歩き等の欄）は、今どのくらい埋まっていますか？ 可能なら一緒に見せてもらう
- B5. 記録をつけていないことで、困ったことや後悔したことはありますか？ それはどんな場面でしたか？

### C. 健診時の体験（8分）★最重要パート

**まず具体的な場面を思い出してもらう**

- ★C1. 一番最近の健診（1歳半または3歳）の問診票を書いたときのことを教えてください。いつ、どこで、誰が書きましたか？
- ★C2. 書くのにどのくらい時間がかかりましたか？
- ★C3. 書いていて「これ、いつだったっけ？」「できてたっけ？」と迷った項目はありましたか？ どの項目でしたか？（下の一覧を見せて指してもらう）
- ★C4. 迷ったとき、実際にどうしましたか？（写真を見返した／パートナーに聞いた／母子手帳を見た／だいたいで書いた／空欄にした）
- C5. それで答えは出ましたか？ どのくらい時間がかかりましたか？
- C6. 健診の当日、保健師さんや医師に聞かれて答えに詰まったことはありますか？
- C7. その結果、何か困ったこと（再確認の連絡・経過観察・自分がモヤモヤした等）はありましたか？
- C8. 次の健診（3歳児健診など）に向けて、何か準備していることはありますか？

#### 問診でよく聞かれる項目（C3で見せる一覧）

> 自治体によって様式や聞き方が違う。可能なら**相手の自治体の実際の問診票**を見せてもらうのが一番よい。以下は一般的な例。

**母子手帳の「保護者の記録」でよく聞かれる時期の記録（月齢を書く欄）**

| 項目 | 写真で分かりそうか |
|------|-----------------|
| 首がすわった | △（写真だけでは判断しにくい） |
| 寝返りした | ○（動画ならより確実） |
| ひとりすわりした | ○ |
| はいはいした | ○（動画なら確実） |
| つかまり立ちした | ○ |
| つたい歩きした | ○（動画） |
| ひとり歩きした | ○（動画） |

**1歳6か月児健診でよく聞かれる項目**

| 項目 | 写真で分かりそうか |
|------|-----------------|
| ひとりで歩けるか（何ヶ月から歩いたか） | ○（動画） |
| 意味のある言葉（有意語・「ママ」「ブーブー」など）をいくつか話すか | ×（動画に声が入っていれば△） |
| 指差しをするか（欲しい物・興味のある物、「○○はどれ？」に指で答える） | △（写真に写ることはあるが判断は難しい） |
| 簡単な指示（「ちょうだい」「ポイしてきて」）が分かるか | × |
| 絵本を見て知っている物を指すか | △ |
| 積み木を積むか | ○ |
| スプーンを使う・コップで飲む | ○ |
| 名前を呼ぶと振り向くか、目が合うか | × |
| まねをするか（バイバイ等） | △（動画） |

**3歳児健診でよく聞かれる項目**

| 項目 | 写真で分かりそうか |
|------|-----------------|
| 階段を上れるか／両足でジャンプできるか | ○（動画） |
| 自分の名前・年齢が言えるか | ×（動画で△） |
| 二語文・三語文を話すか（「ママ、お茶ちょうだい」など） | × |
| 丸を描けるか（クレヨンで○） | ○（描いた絵の写真） |
| ごっこ遊び・ままごとをするか | ○ |
| 友達と一緒に遊べるか | △ |
| 衣服の着脱を自分でするか | △ |
| 色や大小が分かるか | × |
| 目の見え方・耳の聞こえに気になることがあるか（視覚・聴覚検査） | × |

- C9.（一覧を見ながら）この中で、**一番思い出すのに苦労した**項目はどれですか？ それはなぜですか？
- C10. 「初めてできた日」と「遅くともこの頃にはできていた」とでは、問診票を書くときにどちらが分かれば十分だと感じますか？（※ここは意見ではなく、実際どう書いたかを聞く：「実際は何ヶ月と書きましたか？それはどうやって決めましたか？」）

### D. 写真の保存場所と撮影習慣・見返し方（7分）

- ★D1. 子供の写真は月に何枚くらい撮りますか？（今スマホを開いて、先月の枚数を一緒に見てもらうのが確実）
- ★D2. その写真は今どこにありますか？（複数選択）
  - スマホ本体
  - iCloud写真（設定が「iPhoneのストレージを最適化」か「ダウンロードしてオリジナルを保持」か分かれば）
  - Googleフォト（本体から削除しているか）
  - みてね・家族アルバム等の共有アプリ
  - パソコン・外付けHDD
  - パートナーのスマホ（自分では撮っていない）
- ★D3. **生まれた頃の写真**は、今のスマホでそのまま見られますか？（機種変更・容量不足で消していないか）
- D4. スマホの容量がいっぱいになって写真や動画を消したことはありますか？ どうしましたか？
- D5. 写真と動画、どちらをよく撮りますか？ 割合で言うと？（例：写真8：動画2）
- D6. 「歩いた」「はいはいした」ような瞬間は、写真と動画どちらで残っていることが多いですか？
- D7. 主に写真を撮っているのは誰ですか？ パートナーが撮った写真は自分のスマホに入っていますか？
- D8. 最近、昔の子供の写真を探したことはありますか？ 何のために、どうやって探しましたか？ どのくらいかかりましたか？
- D9. 撮った写真を見返すのは、どんなときですか？ 逆に、見返さないのはなぜですか？（「量が多すぎる」「探すのが面倒」「時間がない」など、相手の言葉で）
- D10. お子さんが好きなものや得意そうなことを、普段どうやってつかんでいますか？ 写真を見て「この頃これが好きだったな」と気づいたことはありますか？
- D11. 習い事や遊びを選んだことがあれば、そのとき何を参考にしましたか？（子供の様子、友達、口コミ、家からの近さなど）

### E. 兄弟の有無と写真の混在（2分）※兄弟がいる人のみ

- E1. 兄弟が一緒に写っている写真はどのくらいありますか？
- E2. 写真を見返すとき、上の子か下の子か迷うことはありますか？（特に同じくらいの月齢の頃の写真）
- E3. 下の子の健診のとき、上の子のときの記録と混ざったり、比べたりしたことはありますか？
- E4. 兄弟で記録の量に差はありますか？（「下の子は全然記録していない」など）

### F. 既存アプリの利用（3分）

- ★F1. 子育てで使っているアプリを、ホーム画面で見せてもらえますか？（みてね、ぴよログ、母子手帳アプリ〔母子モ等〕、自治体アプリ、成長記録アプリ等）
- F2. そのアプリで、発達の記録（できたこと）をつけていますか？ 今も続いていますか？
- F3. 健診の問診票を書くとき、そのアプリを使いましたか？ 役に立ちましたか？
- F4. 使い始めたけどやめたアプリはありますか？ やめた理由は？
- F5. みてねを使っている場合：写真はみてねにだけ上げていますか？ スマホ本体にも残していますか？

### G. 支払意思（2分）

**「いくらなら払いますか？」と直接聞くのではなく、過去の支払いを聞く**

- ★G1. 子育て関係のアプリやサービスで、**実際にお金を払ったもの**はありますか？（みてねプレミアム、フォトブック、有料アプリ、写真プリント等）いくら、買い切り／月額どちらでしたか？
- G2. それに払ったのはなぜですか？ 何が決め手でしたか？
- G3. 払うのをやめた（解約した）ものはありますか？ 理由は？
- G4. 普段、アプリに課金するときは買い切りと月額どちらが抵抗が少ないですか？ 過去にどちらで払ったことがありますか？
- G5. 誰が支払いを決めますか？（自分／パートナー／相談して）

### H. プライバシー感覚（1分）

- H1. 子供の写真をSNSに載せていますか？ 載せる場合、顔は出していますか？
- H2. みてねやGoogleフォトなどに写真をアップロードすることに、抵抗はありましたか？
- H3. 写真を読み込むアプリを入れるとき、気にすることはありますか？（過去に許可を拒否したことがあるか）

### I. アイデアの提示と反応（3分）※最後にだけ

- ここで初めてアイデアを短く説明する（30秒以内）
  - 例：「誕生日を入れると、スマホの写真を月齢ごとに並べてくれて、『歩いた』などの印をつけておくと、健診の問診票向けにまとめてくれるアプリを考えています。写真はスマホの外に出しません」
- I1. 聞いてみて、**使う場面**が思い浮かびますか？ それはいつですか？
- I2. 逆に、使わないと思う理由や、引っかかる点はありますか？
- I3. 今日話した中で、一番面倒・困っていることは何でしたか？（アイデアとずれていてもよい）
- I4. 完成したら試してもらえますか？（→ 7章のお願いにつなげる）

> I1〜I4の反応は「褒め言葉」に引っ張られやすい。**判断では I より B〜H の過去の行動を重視**する。

## 4. 誘導質問を避けるための注意点（Mom Test 的な原則）

### 4-1. 基本ルール

1. **未来ではなく過去を聞く**：「使いますか？」ではなく「前回どうしましたか？」
2. **意見ではなく行動を聞く**：「便利だと思いますか？」ではなく「実際に何をしましたか？」
3. **一般論ではなく具体例を聞く**：「普段は〜」ではなく「一番最近の〇〇のとき」
4. **アイデアは最後まで言わない**：先に言うと相手は気を遣って話を合わせる
5. **褒め言葉はデータではない**：「いいね！」「欲しい！」は記録しても判断材料にしない
6. **お金と時間を使ったかで本気度を測る**：困っていると言いつつ何も対策していないなら、課題は弱い
7. **沈黙を怖がらない**：相手が考えているときは待つ。自分で答えの候補を言わない
8. **自分が話す時間は2割以下**：説明しすぎない
9. **「なぜ？」は責めないトーンで**：「どうしてそうしたんですか？」より「そのときどんな感じでしたか？」
10. **深掘りの3点セット**：「それはいつ？」「そのときどうした？」「他に方法は試した？」

### 4-2. 悪い質問例 → 良い質問例

| 悪い質問（誘導・未来・意見） | なぜ悪いか | 良い質問（過去・行動・具体） |
|---------------------------|----------|-------------------------|
| 発達記録アプリがあったら欲しいですか？ | 誰でも「欲しい」と言える。お金も手間もかからない返事 | 子供ができるようになったことを、最後に記録したのはいつですか？ |
| 健診の問診票って書くの大変ですよね？ | 「大変」という答えを誘導している | 前回の問診票を書いたときのことを、最初から教えてもらえますか？ |
| 写真から振り返れたら便利だと思いませんか？ | 同意を求めている | 昔のことを思い出したいとき、実際にどうしていますか？ |
| 500円なら買いますか？ | 仮定の価格には誰でも「買う」と言う | 子育て関係で最近お金を払ったアプリやサービスはありますか？ いくらでしたか？ |
| 記録はつけたいけど時間がないんですよね？ | 答えを先に言っている | 記録をつけなくなったのはいつ頃ですか？ そのとき何がありましたか？ |
| みてねって使いにくくないですか？ | 否定を誘導している | みてねで最近何をしましたか？ 探したい写真が見つからなかったことはありますか？ |
| 普段どのくらい写真を撮りますか？ | 一般論は記憶があいまい | 先月撮った写真の枚数を一緒に見てもいいですか？ |
| こういう機能があればいいと思いますか？（機能を列挙） | 機能のアイデア出しは相手の仕事ではない | 今の方法で一番面倒なのはどこですか？ |
| プライバシーは気になりますか？ | ほぼ全員「気になる」と言う | 写真を読み込むアプリの許可を断ったことはありますか？ それはどんなアプリでしたか？ |

### 4-3. 聞き手のNG行動

- 相手の困りごとに「それ、僕のアプリで解決できます！」と言う
- 相手が「いいね」と言ったときに喜んで話を広げる（→ 話を過去の行動に戻す）
- 自分の仮説に合う話だけメモする（→ 合わない話こそメモする）
- 1回のヒアリングで機能の要望を集めようとする

## 6. ヒアリング後の判断（Go／修正／中止）

5〜10人の結果をもとに、以下で判断する。人数が少ないので**「強い困りごとの具体的エピソードが何人から出たか」を最重視**する。

### Go（このままMVP開発に進む）

次のすべてを満たす：

- [ ] H2（健診で苦労）で、具体的エピソードを話した人が**半数以上**
- [ ] H3（写真で代用）の行動をすでにしている人が**3人以上**
- [ ] H4（写真が端末内にある）が**7割以上**
- [ ] H5（動きの項目で困った）が困った人の中で**半数以上**
- [ ] H8（育児関連で有料サービスに払った経験あり）が**3割以上**
- [ ] テスター協力OKの人が**3人以上**

### 修正（方向を変えて再検証、または機能を絞って進む）

いずれかに当てはまる場合、以下の方向で修正を検討し、必要なら追加で3〜5人に聞く：

| 状況 | 修正の方向 |
|------|----------|
| 健診で困っているが、困った項目が「言葉・指差し」中心 | 写真に加えて**一言メモ・音声メモ**で記録する機能を軸にする／健診前に「今できること」をチェックする機能に寄せる |
| 写真が端末に無い人（Googleフォトのみ・みてねのみ・iCloud最適化）が多い | 対応範囲（iCloud最適化写真の読み込み可否など）を技術的に調べる／対象を「端末に写真がある人」に絞る |
| 兄弟の混在が大きな障害 | 写真ごとに「どの子か」を選ぶ手順をMVPに入れる／まず一人っ子家庭に絞る |
| 健診の困りごとは弱いが「成長の振り返り」自体は好評 | 健診特化ではなく**月齢ごとの振り返り・成長アルバム**に軸を変える（ただし競合が多いので差別化を再検討） |
| 健診の困りごとは弱いが、H10（見返せていない・好きを振り返りたい）が強い | 「好き・夢中の記録」（写真から好きだったものを年表やカードで振り返る）を主軸にする案を検討。**才能や能力の判定はしない**。楽しさ・共有のしやすさで口コミを狙う |
| 課題は強いが支払い経験がほぼ無い | 無料＋広告、または健診まとめPDFのみ有料など**課金ポイントを再設計**／収益化の期待値を下げる判断も含める |
| みてね等で十分という声が多い | みてねとの併用を前提に「健診まとめ」だけに特化する余地があるか検討 |
| 「初めての日」が分からないことへの不満が強い | 「遅くともこの頃にはできていた」で問診票に十分かを、保健師や問診票の書き方から再確認 |

### 中止（または別のアイデアへ）

次のいずれかに当てはまる場合：

- [ ] 健診で困った具体的エピソードを話した人が**2人以下**（課題そのものが弱い）
- [ ] 困っている人はいても、**誰も何の対策もしていない**（写真を見返す・パートナーに聞く等の行動ゼロ）＝本人にとって痛みが小さい
- [ ] 写真が端末に無い人が**半数以上**で、技術的にも解決が難しい
- [ ] 既存アプリで解決済みと言う人が大半

> 中止は失敗ではない。コードを書く前に分かったことが成果。ヒアリングで出た**別の困りごと**（「今日一番面倒なこと」I3）が次のアイデアの種になる。

## 7. ついでにお願いすること（最後の3分）

ヒアリングのお礼を伝えたうえで、無理のない範囲でお願いする。**断りやすい言い方**にする（「もし大丈夫なら」「断ってもまったく問題ないです」）。

### 7-1. Androidテスターの候補

- 背景：Google Playでは、新しく作った個人の開発者アカウントでアプリを公開する前に、**12人以上のテスターに14日間連続でクローズドテストに参加してもらう**ことが求められている（条件は変わることがあるので、申請時にGoogle Play Consoleの最新情報を確認する）
- お願いの内容
  - [ ] Androidスマホを持っているか（本人・パートナー・家族）
  - [ ] テスト用のGmailアドレスを教えてもらえるか
  - [ ] 14日間アプリを入れたままにしてもらえるか（毎日触らなくてもよいか、要件を確認して伝える）
  - [ ] 他にAndroidユーザーの知り合いを紹介してもらえるか
- iPhoneユーザーにも：TestFlight（iOSのテスト配信）で試してもらえるか

### 7-2. その他のお願い

- [ ] 開発の様子を発信するSNS（Xなど）のフォロー
- [ ] 完成時やテスト版ができたときに連絡してよいか（連絡手段：LINE等）
- [ ] 同じ条件（5歳以下の子供がいる）の知り合いを紹介してもらえるか（追加ヒアリング用）
- [ ] 可能なら、自治体の健診問診票（記入前の様式、または個人情報を隠したもの）の写真を見せてもらえるか
- [ ] 完成したアプリへの感想・レビュー（公開後）

### 7-3. お礼

- お礼の品（コーヒーチケット等）を用意するかは事前に決めておく
- 後日、ヒアリング結果をどう活かしたか一言報告すると、テスター協力にもつながりやすい
