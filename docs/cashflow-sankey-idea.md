# 家計の流れ図（サンキー図）ツール 検討メモ

最終更新: 2026-11-24
ステータス: **アイデア整理中（実装はしない）**

子供の発達記録アプリ、ハモリアプリとは別の、3つ目のアイデアです。

---

## 1. アイデアの内容

- 家計のお金の流れを「サンキー図」で見られるようにしたい。
  - サンキー図: 左に収入（給料など）、そこから家賃・食費・貯金などへ太さの違う帯で分かれていく図。帯の太さが金額を表す。
- 家計簿アプリを一から作るのは大変なので、**日本で広まっている家計簿アプリのデータを読み込んで、サンキー図にするだけのツール**として作る（アドイン的な立ち位置）。

## 2. 既存サービスの状況（2026-11-24 調べ）

| サービス | 状況 |
|---|---|
| Monarch Money（アメリカ） | 2023年にサンキー図を追加。図はWeb版のみ。日本の銀行とは連携できない |
| SubFlow（日本のApp Store） | サンキー図を使うが、対象はサブスクの支出だけ |
| マネーフォワード ME / Zaim / Moneytree / Caho家計簿 など | 円グラフ・棒グラフが中心。家計全体の流れ図は見つからなかった |
| SankeyMATIC（無料Webサイト） | 金額を手入力すればサンキー図が作れる。**無料の競合になる** |

→ 日本の家計簿まわりでは、まだ空きがありそう。

## 3. データの受け取り方

日本の家計簿アプリには、外部の人が機能を追加できる仕組み（アドイン）がない。そのため、データの受け取り方は以下に限られる。

| 方法 | 内容 | 判断 |
|---|---|---|
| ① CSV読み込み | ユーザーが家計簿アプリから明細ファイル（CSV＝表形式のデータ）を書き出して読み込む | ◎ **これでいく** |
| ② API連携 | アプリ同士でデータを自動でやり取りする公式の窓口 | △ 個人開発者向けはほぼない（Zaimは以前公開していたが、今使えるかは要確認） |
| ③ ログイン情報を預かって自動で抜き出す | IDとパスワードを預かって画面からデータを取る | ✕ 規約違反になりやすく危険。やらない |

→ 形は「**家計簿アプリのCSVを入れると、その場でサンキー図が出るツール**」。

## 4. 注意点・リスク

- **マネーフォワード ME のCSV書き出しは有料（プレミアム）会員のみ**（アプリ版で1年分）。お客さんが有料会員に絞られる。
- マネーフォワードのCSVは Shift_JIS という文字コード（文字の保存形式）で、扱いを間違えると文字化けする。
- **相手のアプリの都合でCSVの形式が変わると動かなくなる**。そのたびに直す必要あり。
- **本家に真似されやすい**。反応が良ければ大手が同じ機能を付ける可能性。
- **お金のデータはとても敏感**。データをサーバーに送らず、スマホやブラウザの中だけで処理することが大前提。
- 無料のSankeyMATICがあるので、「CSVを入れるだけで自動で分類され、きれいな図になる」くらいの手軽さがないとお金を払ってもらいにくい。

## 5. 進め方（推奨）

1. **Webページ版の試作**: CSVを選ぶとその場でサンキー図が出る1ページだけのツール。ストア審査が不要で一番簡単。
2. **Xなどで見せて反応を見る**: 「マネーフォワードのCSVを入れるだけで家計の流れが図になる」と画像つきで投稿。
3. **反応が良ければ有料化を検討**: 月ごとの比較、家族分の合算、画像で保存、などを追加。
