# 光学ゲームアプリ（アイデア整理中）

3つ目のアプリ案。光学定盤と光学素子の配置を見て、レーザーがどのセンサーに届くかを当てるゲーム。

## 決まったこと（2026-11-27時点）

| 項目 | 内容 |
|---|---|
| 発案者の背景 | 仕事で光学系を使用。担当製品の特性検査と、検査系の調整の経験あり |
| 対象 | 理系学生（特に光に興味のある人）、光学の研究者・技術者 |
| 目的 | 光学の楽しさを広める＋教育（収益化は主目的ではない） |
| 見た目 | 理想は3D。技術的な難しさを見て判断する |

## ゲームの軸（案）

- **予想モード（入口）**：配置を見てセンサーを当てる。「レーザーON」で答え合わせ
- **トラブル診断モード（目玉候補）**：「光が来ない／弱い」原因の部品を当てる。発案者の実務経験が活かせ、前例がほとんどない
- 組み立てモード・調整モード（ミラーのつまみを回す）は後で検討
- 深みを出す要素：偏光（PBS＋波長板）、波長（ダイクロイックミラー）、光の強さ（％）、レンズ

## 技術面の方針（案）

- **計算は2D、見た目は3D**：定盤上の光はほぼ一定の高さで台と平行に進むので、光の進み方は平面上で計算すれば足りる。3Dは見せ方だけにすると、難しさが大きく下がる
- **まずブラウザ版（Webゲーム）から**：URLを共有するだけで授業や研修で使える。インストールもストア審査も不要。3D表示はブラウザ用の部品（three.js）で作れる
- 最初は2Dの試作で「遊んで面白いか」を確かめ、そのあと3D化する
