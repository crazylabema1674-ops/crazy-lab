# ハモリアプリ 壁打ちメモ

最終更新: 2026-11-22
ステータス: **アイデア整理中（実装はしない）**

子供の発達記録アプリとは別の、新しいアプリ案の検討メモです。

---

## 1. アイデアの原点

- ユーザー本人は、洗い物中・通勤の車内・お風呂などで、曲をかけずによく歌っている。
- 新しい楽しみとしてハモリに挑戦したが、やり方が分からず断念した。
- YouTubeで「サビのハモリだけを歌っているチャンネル」を見つけ、それに重ねて歌うと **1人で歌うよりずっとうまく聞こえて楽しかった**。
- → 「誰々の〇〇を一緒に歌おう！」と声で頼むと、ハモリを歌ってくれるアプリがあれば素敵。

### 本人の理想像
ハモリに特化したAIに「〇〇を歌おう」と言うと、うまくハモリパートを作ってくれる。歌いながら「もっと高く」などとお願いすると調整してくれる。

## 3. 作り方の候補

| | 案1: 曲ごとのハモリ音源を流す | 案2: 声を聞いて自動でハモる | 案3: 曲名からAIがハモリを作る |
|---|---|---|---|
| 体験の近さ（本人のYouTube体験） | ◎ | △（自分の声っぽくなる） | ○ |
| 歌える曲 | 用意した曲だけ | どんな曲でも | 多い |

## 4. 現時点で見えている論点・リスク

1. **著作権（最重要）**: 既存曲のハモリを作って配信すること自体が、曲の「編曲」にあたる可能性がある。YouTubeの「歌ってみた」はYouTubeと著作権団体の包括契約で成り立っているが、自前のアプリでは同じ仕組みが使えない可能性が高い。→ 専門家・公式情報で要確認（未確認）。
2. **YouTubeとの違い**: すでにYouTubeで体験できている。アプリにする理由（お金を払う理由）は何か。
3. **声で操作する場面の音響**: お風呂・車内でスピーカーから音を出すと、マイクがアプリ自身の音も拾ってしまう。
4. **「別の歌手の声」をリアルタイムで作るのは難しい**: 声をその場で別人の声に変えると、遅れ（ズレ）が出やすい。

## 5. 新しい有力案: 「1回歌うと、AIがハモリを返してくれる」型

AIは流行りの曲のメロディを正確には覚えていない。原曲の音源をアプリで分析することも、配信サービス（Spotify等）の規約上ほぼできない。
→ **メロディの情報源を「ユーザー自身の歌声」にする**。

1. ユーザーが「〇〇を歌うね」と言って、1曲（または1コーラス）歌う
2. AIが歌声から音程とリズムを読み取り、曲の調（キー）を推定してハモリの音を決める
3. ユーザーの録音の音程をハモリの音に移し、声質を「別の上手な歌手の声」に変換して返す（歌詞もテンポもユーザーの歌がもとなので自然に合う）
4. 2回目からはそれに重ねて歌う。「サビはもっと高く」などと声で頼むと作り直す

- 良い点: どんな曲でも1曲まるごと対応。アプリが曲のデータを持たない。本人の「好きなテンポ」にも合う。
- 課題:
  - 技術的に難しい（声質の変換は端末内では重く、サーバーで処理する可能性大 → サーバー代がかかり、買い切りより月額向き）
  - 「別の歌手の声」のもとになる声の権利（声の提供者の許可が必要）
  - 著作権: アプリが曲を配信しないので案1より有利と思われるが、未確認。専門家への確認が必要
  - 最初の1回はハモリなしで歌う必要がある（すぐ一緒に歌えるわけではない）

## 6. 方向性の候補（検討中・旧）

- A. **ハモリ再生型**: 曲ごとのハモリ音源に合わせて歌う（案1）。体験は一番近いが、著作権と音源づくりが課題。
- B. **ハモリ練習型**: ハモリの歌い方を教える。本人の「ハモれるようになりたい」に応える。
- C. **A＋Bの組み合わせ**: 最初は重ねて楽しむ → 慣れたら自分でハモる側に回る。
